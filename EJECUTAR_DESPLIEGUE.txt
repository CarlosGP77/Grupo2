════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════════

❌ "Connection refused"
   Espera más tiempo (40-60 segundos) a que inicie

❌ "docker: command not found"
   Docker no está instalado. Instala con:
   sudo apt-get install docker.io docker-compose

❌ "Permission denied"
   Algunos comandos necesitan sudo:
   sudo docker-compose up -d --build

❌ "Port already in use"
   Otro servicio está usando el puerto 8080
   Cambia en docker-compose.yml: "8081:8080"

❌ "git pull" muestra conflictos
   Contacta con el administrador del repositorio
